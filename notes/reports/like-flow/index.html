研究レポート 01（抜粋）

マッチングアプリのいいねの流れのシミュレーション男女の非対称と先行研究との一致

laplaciannin102

2026年11月8日（11月11日改訂）

要旨

マッチングアプリを題材にしたゲーム Heartfolio のために、ある男女の組で「プロフを見ていいねする確率」と「届いたいいねに返す確率」を表すモデルを作り、仮想の利用者どうしにいいねを送り合わせるシミュレーションを行った。送ったいいねがマッチになる割合は、男性から女性へが約18%、女性から男性へが約41%で、男性が受け取るいいねは一部の人に強く集中した（ジニ係数 0.60）。また、モデルに前提として入れていない傾向、すなわち「自分より望ましい相手にいいねを送る」「差が大きいほど返されにくい」「マッチした二人の魅力が似る」が、結果として現れた。いずれもオンラインの出会いや恋人どうしについての先行研究と、向きがおおむね一致する。ただし魅力の相関は、先行研究が外見の魅力を測っているので、大きさの比較は目安にとどまる。

この文書は、研究の一部を抜き出したものです。式は、いいねする確率の形だけを載せています。パラメータの値と較正の手順の細部は載せていません。

1.はじめに

ゲームの中では、お相手（CPU）が毎日だれかのプロフを見て、いいねするかを決める。プレイヤーから届いたいいねに返すかも決める。この判断がでたらめだと、マッチングアプリらしい手ざわりは出ない。人気の人にはいいねが集まり、高望みのいいねはなかなか返ってこない、という感覚が要る。

そこで、判断を確率のモデルで表し、それを多くの仮想の利用者に当てはめたとき、全体としてどんな流れになるかを調べた。確かめたかったのは二つである。一つは、男女でいいねの送り方と受け取り方が違うという、よく知られた非対称が出るか。もう一つは、モデルに直接入れていない傾向が、先行研究の知見と合う形で現れるかである。

2.方法

2.1 なぜ式で表すか

判断を学習モデルで表す案も検討した。正解のラベルを言語モデルに付けさせ、それを学習させてブラウザで動かす方法である。しかし、ラベルを作る手間が大きく、言語モデルの付けたラベルが現実の判断を表している保証もない。ゲームに要るのは、もっともらしい確率が手軽に出ることなので、少数の考え方を組み合わせた式で表すことにした。式であれば、どの要素がどう効くかを説明でき、ブラウザの中で計算できる。

2.2 モデルの考え方

利用者は、性別・年齢と、6つの属性を持つ。属性は2種類に分けた。

  • 縦型の属性（顔・年収・学歴）：高いほど、だれからも好まれる。
  • 横型の属性（アウトドア度・社交性・家庭志向）：自分の理想に近いほど好まれる。有利な値は人ごとに違う。

相手をどれだけ好むかは、これらの属性と年齢の近さ、好みの個人差、二人の組ごとに決まる相性の揺らぎから決まる。縦型の属性からは、異性から見た「市場価値」を作る。いいねする確率と返す確率は、別々の式で表し、次の要素を使い分けた。

  • 好みと相性：相手を好むほど、いいねしやすく、返しやすい。
  • 相手の人気：市場価値が平均より高い相手ほど、選ばれやすい。
  • 高嶺の花（いいねするとき）：自分より市場価値の高い相手ほど、その差のぶん、いいねをためらう。
  • 自分の基準（返すとき）：返すかどうかは、自分の市場価値が高いほど厳しくなる。

たとえば多次元のモデルでは、プロフを1回見たときにいいねする確率を、次の式で表した。

Pいいね =σ(α+βU−ρD) D =max(0,V相手−V自分)
(1)
  • U：相手をどれだけ好むか。好みと相性に、相手の人気の分を足したもの
  • V：市場価値。D：相手の市場価値が自分を上回るぶん（下回るときは 0）。U・V・D は、属性の10点を 1 と数える
  • α：平均のいいね率を合わせる定数。β：選り好みの強さ。ρ：高嶺の花の強さ。どれも男女で値が違う
  • σ：どんな値も 0〜1 の確率に変える S 字の関数。σ(z)=1/(1+e−z)

相手を好むほど、確率は上がる。高嶺の花の項 ρD は、相手の市場価値が自分より高いときだけ、S 字の関数に入れる前の値から、その差に比例するぶんを引く。市場価値の高い相手は好まれやすくもあるので、多くの場合、確率は下がらずに、上がり方がゆるやかになる。返す確率は、S 字の関数に、返す率の上限を掛けた形で表し、自分の市場価値が高いほど基準が厳しくなるようにした。

この形には、先行研究の裏付けがある。好みを数で表し、S 字の関数で確率に変える形は、オンラインの出会いで最初に連絡するかどうかの分析にも使われている[3]。その分析も、相手と自分の属性の差を、相手が上のときと下のときに分けて扱っている。高嶺の花の項を入れたのは、人は自分より望ましい相手に連絡するが、どこまで上を狙うかは自分の望ましさに応じて決まる、という知見[1]に合わせるためである。一方で、自分の魅力によらず、魅力的な相手ほど連絡されやすいという観察もある[3]。この観察は、送り手を外見の評価で分けて平均したものである。式(1)でも、送り手を自分の市場価値で分けて平均すると、どの層でも、相手の顔の点が高いほど確率は上がる。

平均のいいね率は、男性のほうが気軽にいいねし、女性は選り好みするという前提で、男女で差を付けた。

2.3 シミュレーション

男女同数の仮想の利用者を作り、期間を区切って、毎ターンいいねを送り合い、返し合わせた。男性は1ターンあたり女性より多く送る。比べるために、魅力を1つの数にまとめたモデル（以下、1次元）と、属性を分けたモデル（以下、多次元）の二つを用意し、多次元では選り好みの強さを調整して、受け取るいいねの分布を1次元にそろえた。主な指標は乱数の種を変えて10回くり返し、ばらつきが小さいことを確かめた。

人気の偏りは、受け取ったいいねの数のジニ係数で見た。0 なら全員が同じ数を受け取り、1 に近いほど一部の人に集中している。

3.結果

3.1 男女の非対称

1人あたりの受け取ったいいねは、平均で男性が約45、女性が約100で、女性が約2.2倍だった。マッチは男女1組で1つと数えるので、男女同数の利用者では、マッチの数の平均は男女で同じになる（約36）。男性は、受け取るいいねが少ないぶんを、自分から多く送ることで補っている（図1）。

男性は送る数が多く、返ってくる割合が低い。女性は受け取る数が多い。送ったいいねがマッチになった割合は、男性から女性へが約18%、女性から男性へが約41%だった（図2）。

受け取るいいねの偏りは、男性のほうが大きい。ジニ係数は男性 0.60、女性 0.41 で（図3）、男性では、多くのいいねを受け取る少数の人と、ほとんど受け取らない多くの人に分かれた。プレイヤーが男性なら、送ったいいねの大半が返ってこないのが、このモデルでは「ふつう」になる。

3.2 被好意数という見方

受け取ったいいねの数だけでは、好意を得た量を測りきれない。受け取るいいねが少ない人も、自分から送って返してもらうことで好意を得ているからである。そこで「自分にいいねしてくれた人」と「自分がいいねして返してくれた人」を合わせた人数（重なりは1人と数える）を、被好意数と呼んで数えた。被好意数のジニ係数は、受け取ったいいねの数のジニ係数より小さく、偏りは見かけほど大きくない。

3.3 1次元と多次元

1次元の「魅力」は、顔・年収・学歴などをまとめた総合の評価と考えられる。そのため、受け取るいいねの分布は、どちらのモデルでも近くなるのが自然である。実際、選り好みの強さが同じままだと、多次元のほうが集中は弱かった。横型の属性や好みの個人差のぶん、だれから見ても魅力的という成分が薄まるためである。選り好みを強めると、分布はほぼ重なった（表1）。

表1　選り好みの強さを合わせたあとの、受け取るいいねのジニ係数（1次元と多次元の値）
受け取る側二つのモデルの値
女性0.406 と 0.406
男性0.596 と 0.599

選り好みの強さをそろえたまま比べると、好みの個人差が大きいほど人気の集中が和らぎ、マッチの総数が増えた。好みがばらけているほうが、いいねが多くの人に行き渡る。

受け取るいいねを左右する属性は男女で違い、男性では年収・顔・学歴の順に効き、女性では顔の影響が大きかった。横型の属性は、だれにとって有利かが人によるので、全体として有利な値はない。ただし似た者どうしは結ばれやすく、横型の属性の差は、ランダムな組、いいねした組、マッチした組の順に小さくなった（図4）。

4.先行研究との比較

モデルに前提として与えていない次の傾向が、結果として現れた（表2）。

表2　先行研究の知見と、本モデルの結果
先行研究の知見本モデル
人は自分より望ましい相手に連絡する。望ましさの順位で、平均約25%上[1]いいねの7〜8割が自分より人気の相手へ。魅力の比の中央値で14〜33%上（研究は順位の差、本モデルは魅力の比なので、比べられるのは向きまで）
望ましさの差が大きいほど返信されにくい[1]男性が女性に送ったいいねでは、魅力の差が小さいと約27%、相手の魅力が大きく上だと約2%が返ってきた
恋人どうしの外見の魅力の相関は約0.39[2]マッチした二人の相関は 0.40（1次元）、0.29（多次元）
男性が受け取るいいねのジニ係数は約0.54〜0.58（非公式な集計。少人数の調査などからの推計で、目安）0.60

魅力の相関は、いいねの段階では約0.1と小さく、返すかどうかの段階で大きくなった（図5）。送るときはだれもが上を目指し、受け入れられるのは釣り合う相手、という構造である。ゲームの中では、高望みのいいねがなかなか返ってこない体験になる。ただし、先行研究の値は外見の魅力の相関で、本モデルの魅力は顔・年収・学歴などをまとめた値である。同じ量ではないので、大きさの比較は目安にとどまる。

5.モデルの前提と限界

  • プロフの情報は正確で、全員が全員の属性を知っている前提である。
  • 好みや返す基準は、時間がたっても変わらない。妥協も高望み化も起きない。
  • マッチしたあとの行動（メッセージ・デート・交際）は扱っていない。ゲームのデートや交際の確率は、このモデルの外で決めている。
  • 異性間のいいねだけを扱っている。
  • 式(1)は、一人ひとりで見ると、相手の顔をあまり重く見ない女性で、自分より市場価値の高い相手の顔の点が上がると、確率がわずかに下がることがある。先行研究[3]の観察は集団の平均で、こうした一人ひとりの反応までは確かめられていない。

6.今後

先行研究から見て、次の二つを足す余地がある。男性が好む年齢差を、年齢とともに広げること[4]。マッチできない日が続くと基準を下げること[5]。また、ゲームのプレイの記録が集まり、式では表せない傾向が見えてきたら、学習するモデルへの置き換えも考える。

このモデルは、Heartfolio の中でお相手がいいねする確率・返す確率として使っている。ただし、この文書の数値は研究した時点（2026年11月初め）の版で測ったもので、ゲームではそのあと、返す確率の合わせ直しと属性の追加をしている。形のイメージは、ホームページの「しくみ」のページで触って確かめられる。
